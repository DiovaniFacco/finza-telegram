What is Finza?

A personal finance companion that lives where you already are — inside Telegram.

Finza turns a chat into a ledger. You type expenses the way you'd say them out loud, and the bot does the rest: it extracts the amount, figures out the merchant, assigns a category, and writes it to a Postgres database.

A web dashboard visualizes everything — daily/weekly/monthly trends, categories, cumulative balance, and your top merchants — in a fast, glassy interface that works on desktop and mobile, light and dark.

Sign-in is passwordless: the bot issues a short-lived magic link, so there are no accounts to create and no credentials to leak.

Architecture at a glance

FastAPI serves the webhook, dashboard and exports; a `python-telegram-bot` application runs in webhook mode; APScheduler fires the nightly report job. Deployed on Railway with a Supabase Postgres database.

Secure by default

The webhook lives behind a secret path segment, session cookies are signed and HttpOnly, and every dashboard query is scoped to the authenticated user.
